# iximiuz-labs-postgresql-19-playground

This repository contains
- The Virtual Machine Image in the form of a container image (Dockerfile only) for the iximiuz Labs PostgreSQL 19 playground. In iximiuz Labs, we refer to the custom VM image as custom rootfs image. A custom rootfs image is a container image, which is used to provide the VM image for the iximiuz Labs playground
- The iximiuz Labs PostgreSQL 19 playground manifest YAML
